## 2. 날씨: 기상청 단기예보

**준비**
- 공공데이터포털에서 "기상청_단기예보 조회서비스" 활용신청
- 인증키는 **Decoding 키**를 `requests`의 `params`에 넣으세요. Encoding 키를 쓰면 이중 인코딩으로 인증 오류가 자주 납니다.
- `dataType=JSON`으로 받으면 XML 파싱이 필요 없어요.

**격자 변환** (기상청 공개 공식)
```python
import math
def to_grid(lat, lon):
    RE, GRID, SLAT1, SLAT2, OLON, OLAT, XO, YO = 6371.00877, 5.0, 30.0, 60.0, 126.0, 38.0, 43, 136
    D = math.pi / 180.0
    re = RE / GRID
    s1, s2, olon, olat = SLAT1*D, SLAT2*D, OLON*D, OLAT*D
    sn = math.log(math.cos(s1)/math.cos(s2)) / math.log(math.tan(math.pi*0.25+s2*0.5)/math.tan(math.pi*0.25+s1*0.5))
    sf = math.tan(math.pi*0.25+s1*0.5)**sn * math.cos(s1) / sn
    ro = re * sf / math.tan(math.pi*0.25+olat*0.5)**sn
    ra = re * sf / math.tan(math.pi*0.25+lat*D*0.5)**sn
    theta = lon*D - olon
    theta = (theta + math.pi) % (2*math.pi) - math.pi
    theta *= sn
    return int(ra*math.sin(theta) + XO + 0.5), int(ro - ra*math.cos(theta) + YO + 0.5)
```
서울시청(37.5665, 126.9780)을 넣어 `(60, 127)`이 나오면 정상이에요.

**발표 시각(base_time) 규칙**
단기예보는 하루 8번(02, 05, 08, 11, 14, 17, 20, 23시) 발표되고, 발표 후 10분쯤 지나야 조회됩니다. 현재 시각보다 이전의 가장 최근 발표 시각을 계산해야 해요. 자정 직후면 전날 23시로 넘어가는 처리도 필요합니다.

**쓸 항목**
| 코드 | 뜻 |
|---|---|
| TMX / TMN | 일 최고 / 최저기온 |
| TMP | 시간별 기온 |
| REH | 습도 |
| WSD | 풍속(m/s) |

TMX, TMN은 특정 시각 예보에만 들어 있어서, 없으면 TMP 중 최댓값·최솟값으로 대신하세요.

**체감온도**: 이틀 범위라면 여름은 TMX를 그대로 쓰고, 겨울만 풍속을 반영하는 공식으로 계산하는 걸 추천해요.
```python
def wind_chill(t, wsd_ms):
    v = wsd_ms * 3.6  # km/h
    return 13.12 + 0.6215*t - 11.37*v**0.16 + 0.3965*v**0.16*t
```

## 3. 쉼터: CSV

- 공공데이터포털에서 무더위쉼터, 한파쉼터 파일을 받아 **시연 지역(예: 서울)만 남겨** 작게 만드세요.
- 받은 뒤 위도·경도 컬럼이 있는지 먼저 확인하세요. 없는 행은 버립니다.
- 지금이 10월이라 시연 때는 계절을 파라미터로 받아서 여름/겨울을 골라 보여주면 돼요.

```python
def haversine(lat1, lon1, lat2, lon2):
    R = 6371000
    p1, p2 = math.radians(lat1), math.radians(lat2)
    dp, dl = p2 - p1, math.radians(lon2 - lon1)
    a = math.sin(dp/2)**2 + math.cos(p1)*math.cos(p2)*math.sin(dl/2)**2
    return 2 * R * math.asin(math.sqrt(a))
```
pandas로 CSV를 읽고 거리 컬럼을 계산해서 가까운 3곳만 반환하면 끝이에요.

## 5. MCP 

함수가 완성되면 FastMCP로 감싸는 건 몇 줄이에요.
```python
from mcp.server.fastmcp import FastMCP
mcp = FastMCP("safety-tools")

@mcp.tool()
def weather(lat: float, lon: float) -> dict:
    return get_weather(lat, lon)

@mcp.tool()
def shelters(lat: float, lon: float, season: str) -> list:
    return get_shelters(lat, lon, season)
```
함수와 MCP를 분리해두면, MCP 연결이 막혀도 오케스트레이터가 함수를 직접 부르는 방식으로 바로 되돌릴 수 있어요.
