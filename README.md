# AIO 교육 프로젝트 백업

이 폴더는 AIO 교육 과정의 팀 프로젝트와 학습 자료를 보관하는 작업본입니다. 현재 맥의 위치는 `/Users/rola/aio_project`이며, [공개 GitHub 저장소](https://github.com/jasnok/aio_project)에도 보관 범위를 정해 업로드했습니다. 원본 자료는 Windows에서 2026-11-05에 백업했고, 2026-11-17 기준 맥의 현재 폴더 구조를 이 문서에 반영했습니다.

## 폴더 구성

```text
aio_project/
├── source/
│   ├── aio-teamproject/       # 팀 프로젝트와 관련 작업본
│   └── aio_LearningMaterials/ # 수업 자료와 실습 프로젝트
├── GITHUB_백업범위.md
├── Git_플랫폼_점검.md

├── 프로젝트별_복구정보.md

```

`aio-teamproject`에는 1~4차 팀 프로젝트와 5차 프로젝트 안내가 있습니다. 진행 중인 5차 프로젝트 `chaja-you`의 작업본은 별도 경로 `/Users/rola/chaja-you`에 있으며 [팀 저장소](https://github.com/ik-e/chaja-you)와 연결됩니다. `aio_LearningMaterials`에는 날씨 MCP 배포 실습, `aidevs`, `aio-01d4-stu`, `mini`, `mini_agent`, `mini_multi_agent`, `optional_multimodal_agent`가 있습니다. 각 폴더의 README와 의존성 파일이 개별 프로젝트의 우선 안내입니다.

기존 `aio-wt` 작업본과 `lawpath-campus-submission` 사본은 현재 GitHub 트리에서 정리하고 `/Users/rola/aio_project_backup/정리보관_2026-11-17`에 별도 보관했습니다. 두 폴더의 이전 GitHub 버전은 과거 커밋에도 남아 있습니다. `aio-wt`에는 본 프로젝트와 다른 발표 자료와 작업 버전이 포함됩니다.

## 로컬과 GitHub의 차이

GitHub는 보안 및 복구상의 이유로 로컬 폴더의 완전한 복사본이 아닙니다. 실제 환경설정, 중첩 프로젝트의 Git 이력, 로컬 데이터베이스와 실행 로그 등을 제외했습니다. 일부 `.env.example`은 포함되어 있지만 확인이 필요한 예시 파일 하나는 제외했습니다. 구체적인 범위는 [GitHub 백업 범위](GITHUB_백업범위.md)를 참고하세요. 로컬에는 중첩 Git 저장소와 실제 `.env`가 남아 있을 수 있습니다.

GitHub 저장소 자체의 커밋 이력은 있지만, 각 프로젝트의 원래 Git 이력과 worktree 관계를 이 백업으로 복원할 수 있다고 가정하면 안 됩니다. API 제공업체의 파일·벡터 저장소와 외부 서비스 데이터도 별도 확인이 필요합니다.

2026-11-17에 GitHub 갱신 후 맥의 루트 브랜치와 인덱스를 원격 기준으로 맞췄습니다. 별도 프로젝트의 작업 중인 변경과 GitHub에 올리지 않은 로컬 파일은 보존했으므로 Git 상태에 변경 사항으로 표시될 수 있습니다. Git 명령을 실행하기 전에 대상 파일과 상태를 확인하세요.

## 맥에서 복구하거나 실행할 때

1. `source`에서 필요한 프로젝트를 별도 작업 폴더에 복사하고 해당 프로젝트의 README를 읽습니다.
2. Python·Node.js·Docker 등 필요한 도구와 의존성을 프로젝트 안내에 맞게 설치합니다. 문서에 Windows PowerShell 명령이나 `C:\` 경로가 있다면 macOS 환경에 맞게 조정합니다.
3. 환경변수 예시가 있다면 내용을 확인한 뒤 별도 `.env`를 만들고 필요한 값을 안전하게 설정합니다. 예시가 없으면 코드와 문서에서 변수 이름을 확인합니다. 실제 비밀값은 Git에 올리지 않습니다.
4. 필요한 외부 API, 데이터베이스 및 모델 리소스를 별도로 준비합니다.
5. 새 작업 폴더에서 실행하고 결과와 누락 사항을 기록합니다. 전체 프로젝트의 맥 복구 및 실행은 아직 검증하지 않았습니다.
