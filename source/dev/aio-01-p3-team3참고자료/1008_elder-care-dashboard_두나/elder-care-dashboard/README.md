# 온기케어 보호자 대시보드

노인 케어 멀티 에이전트 프로젝트의 프런트엔드 UI 프로토타입입니다.

## 실행

`index.html`을 Chrome 또는 Edge로 열면 별도 설치 없이 실행됩니다.

## 시연 순서

1. 왼쪽 관리 대상자 탭에서 5명의 가상 어르신을 전환합니다.
2. 치매 관리 대상자인 `이명자`를 선택해 GPS 위치, 안전구역, 수신 시각과 배터리를 확인합니다.
3. `긴급상황 재현` 버튼으로 바이탈·온도 이상을 만듭니다.
4. 우측 승인 패널에서 근거와 처리 상태를 확인합니다.
5. `119 신고 승인`을 눌러 보호자 승인 모달을 확인합니다.
6. `툴 실패 재현`으로 3회 재시도와 최종 대체 처리 흐름을 확인합니다.
7. 화면 상단의 한 줄 진행 상태로 백엔드에서 프런트엔드까지의 처리를 확인합니다.

현재 버전은 UI 검증용 정적 프로토타입이며 실제 센서, CCTV, FastAPI, MCP와 연결되어 있지 않습니다.
