# 교육 프로젝트 로컬 백업

백업일: 2026-11-05

## 범위
source 폴더에 C:\dev, C:\mini_agent, C:\mini_multi_agent, C:\optional_multimodal_agent, C:\mini, C:\aio-01d4-stu의 복사 시점 파일을 보관합니다. 각 프로젝트의 README와 의존성 파일을 먼저 확인하세요. 로컬에서 커밋하지 않은 파일도 제외 규칙에 해당하지 않으면 포함됩니다.

## 제외 및 제한
.git 이력, node_modules, 가상환경, 빌드·캐시 폴더, .env와 .env.* 파일, 인증서·키 파일, 로그는 제외했습니다. 따라서 예시 환경변수 파일(.env.example)도 제외되어 원본에서 비밀값 없이 다시 작성해야 합니다. Git 커밋 이력과 브랜치, 삭제된 파일의 이전 버전은 이 복사본에 없습니다. 원본 저장소를 삭제하지 마세요. C:\aio-01d4-stu에는 원격보다 앞선 커밋과 작업 중 변경사항이 있었습니다.

개인정보·비밀값은 단순 자동 검사로 모두 발견할 수 없습니다. 공유하거나 업로드하기 전 별도 검토가 필요합니다. OpenAI 플랫폼의 Files, Vector Store, Fine-tuning과 배포 서비스 설정은 이 로컬 복사에 포함되지 않으며 직접 확인해야 합니다.

## 복구 점검
1. source에서 필요한 프로젝트를 별도 위치에 복사합니다.
2. 해당 프로젝트의 README와 의존성 파일을 따라 환경을 설치합니다.
3. 환경변수 이름을 코드와 문서에서 확인해 .env.example을 작성하고, 실제 값은 안전하게 별도 설정합니다.
4. OpenAI 및 외부 서비스 리소스를 개인 계정에서 재구성하고 연결합니다.
5. 대표 기능을 실행하고 결과와 누락 사항을 기록합니다. 복구 실행은 아직 확인하지 않았습니다.

이 폴더는 C드라이브에 있는 로컬 사본입니다. 드라이브 장애에 대비하려면 검토 후 별도 저장장치 또는 접근 권한이 있는 안전한 저장소에 추가 사본을 만드세요.

## 보안 검사 상태
일부 텍스트 파일에서 비밀값 형태와 일치하는 문자열이 발견되었습니다. 실제 비밀값인지 확인하지 않았으며, 해당 파일은 아직 복사본에 남아 있습니다. 이 백업을 공유하거나 업로드하지 마세요. 자동 검사에는 한계가 있으며 전체 보안 검토는 완료되지 않았습니다.
