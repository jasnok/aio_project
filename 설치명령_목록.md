Python 가상환경을 사용하는 경우 해당 프로젝트 디렉터리에서 다음과 같이 만들고 활성화할 수 있습니다. 프로젝트별 Python 버전과 의존성은 각 README를 따르세요.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```
