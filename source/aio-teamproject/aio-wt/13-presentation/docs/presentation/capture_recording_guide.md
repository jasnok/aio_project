# README용 화면 캡처·GIF·영상 가이드

## 1. 원칙

- 가능하면 `localhost`가 아니라 실제 배포 도메인이 보이게 촬영합니다.
- 실제 개인정보와 운영용 API 키가 없는 발표 전용 계정·데이터를 사용합니다.
- 관리자 API 인증이 적용되기 전이라면 운영 데이터로 관리자 앱을 공개 배포하지 않습니다.
- 관리자 공개 시연이 꼭 필요하면 별도의 임시 Supabase 프로젝트와 가짜 데이터만 사용하고 발표 후 내립니다.
- 한 화면에서 설명할 메시지는 하나만 남기고 브라우저 알림·북마크·개인 탭은 숨깁니다.

## 2. 촬영 전 데이터 준비

최소 12~15개의 데모 공고를 준비하면 페이지네이션과 정렬을 함께 보여 줄 수 있습니다.

| 데이터 | 준비 이유 |
| --- | --- |
| 오늘 마감 공고 | `D-DAY` 표시 |
| 3일 뒤 마감 공고 | `D-3` 표시 |
| 이미 마감된 공고 2건 이상 | 흐린 카드와 후순위 이동 |
| 면적·모집인원 차이가 큰 공고 | 오름·내림 정렬 확인 |
| 보증금·월세 차이가 큰 공고 | 금액 정렬과 가독성 확인 |
| 이미지 3장 이상 공고 | 갤러리 시연 |
| 총 11건 이상 | 10건 단위 페이지 이동 시연 |
| 삭제 전용 가짜 공고 3건 | 전체·선택 삭제 안전 시연 |

## 4. 추천 영상 구성

### 2분 30초 전체 데모 영상

| 시간 | 내용 | 발표 멘트 핵심 |
| --- | --- | --- |
| 0:00~0:10 | 브라우저 주소창과 서비스 홈 | 실제 배포 환경임을 확인 |
| 0:10~0:40 | 사용자 목록 | D-day, 평수, 읽기 쉬운 금액 |
| 0:40~1:05 | 검색·10가지 정렬 | 목적에 맞게 빠르게 비교 |
| 1:05~1:20 | 페이지 이동·상세 이미지 | 많은 공고와 여러 사진 탐색 |
| 1:20~1:50 | 관리자 수동 등록 | 반복 등록을 위한 값 유지와 초기화 |
| 1:50~2:20 | 관리자 선택 삭제 | 대상 확인과 성공·실패 피드백 |
| 2:20~2:30 | Swagger 또는 아키텍처 | UI·API·DB가 연결된 결과 강조 |

## 5. 촬영 설정

- 해상도: 1920×1080 권장
- 브라우저 배율: 100%부터 시작하고 글자가 작으면 110% 사용
- 영상: 30fps, MP4
- GIF: 한 동작당 6~12초, 1280px 안팎, 10~15fps
- 마우스는 천천히 움직이고 클릭 후 화면 반응이 끝날 때까지 기다립니다.
- 주소창은 영상 시작과 마지막에 2초 이상 보여 줍니다.
- 본문 시연 중에는 전체 화면을 사용해도 되지만 도메인이 확인되는 장면을 남깁니다.

Windows에서는 캡처 도구의 화면 녹화나 OBS를 사용할 수 있습니다. 전체 데모는 MP4로 녹화하고, README에는 핵심 동작만 짧은 GIF로 변환하는 구성이 읽기 쉽습니다.

## 7. 안전 체크리스트

- [ ] `.env`, Streamlit secrets, Supabase key가 화면에 나오지 않음
- [ ] 관리자 비밀번호를 입력하는 장면은 잘라내거나 가림
- [ ] 개인 이메일·실명·전화번호가 없음
- [ ] 삭제 시연 데이터는 다시 만들어도 되는 가짜 데이터임
- [ ] 개발자 도구 Network 탭에 인증 토큰이 보이지 않음
- [ ] 공식 공고 이미지는 발표·프로젝트 설명 범위에서 필요한 만큼만 사용
- [ ] 배포 URL, Swagger URL, 저장소 URL이 발표 직전에 정상인지 확인
- [ ] Render·Streamlit 콜드스타트를 고려해 발표 10분 전에 한 번 접속

## 8. 촬영 순서

1. 테스트 데이터와 계정을 초기화합니다.
2. 브라우저를 새 프로필 또는 게스트 모드로 엽니다.
3. 알림과 자동완성을 끄고 개인 북마크를 숨깁니다.
4. 전체 데모 MP4를 먼저 한 번에 녹화합니다.
5. 같은 흐름에서 짧은 GIF용 동작을 각각 다시 녹화합니다.
6. PNG는 동작이 끝난 안정된 화면에서 캡처합니다.
7. README에 넣고 GitHub 렌더링과 모바일 너비를 확인합니다.
8. 발표 당일에는 영상 파일과 PDF 형태 README 백업도 준비합니다.
