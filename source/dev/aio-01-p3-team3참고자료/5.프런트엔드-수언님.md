프런트 담당은 **"시연에서 팀의 모든 작업을 눈에 보이게 만드는 사람"**이에요. 심사위원이 실제로 보는 건 이 화면이라 생각보다 중요합니다.

## 1. 해야 할 일 / 하지 말아야 할 일

| 해야 할 일 | 하지 말아야 할 일 |
|---|---|
| 프로필 선택, 실행, 결과 표시 | 위험도 계산 등 로직 넣기 (백엔드 담당) |
| 장애 주입 옵션과 복구 과정 표시 | API 키를 화면 코드에 넣기 |
| 백엔드 오류 시 안내 문구 표시 | 실제 지병명 표시 |

## 2. 화면 구성

```
┌─────────────────────────────────────────────┐
│ 사이드바                                      │
│  - 테스트 인물 선택 (3명)                       │
│  - 계절 선택 (여름 / 겨울)                       │
│  - 장애 주입: □ 기상청 API  □ LLM 형식 오류        │
│  - [알림 확인하기] 버튼                          │
├──────────────────────┬──────────────────────┤
│ 👵 어르신용 카드         │ 👨‍👩‍👧 보호자용 카드        │
│ (큰 글씨, 위험도 색)      │ (위험도, 이유, 쉼터)      │
├──────────────────────┴──────────────────────┤
│ 🔧 실행 과정 (AutoHealing 로그)                 │
│ weather  1회차 실패 → 2회차 실패 → 캐시 사용 ✅     │
│ 데이터 기준: 14시 예보 (캐시)                      │
└─────────────────────────────────────────────┘
```

**위험도 색상**
| 관심 | 주의 | 경고 | 위험 |
|---|---|---|---|
| 초록 | 노랑 | 주황 | 빨강 |

## 3. 코드 뼈대

```python
import streamlit as st, requests

API_URL = st.secrets.get("API_URL", "http://localhost:8000")
COLORS = {"관심": "#2e7d32", "주의": "#f9a825", "경고": "#ef6c00", "위험": "#c62828"}

st.set_page_config(page_title="폭염·한파 안전 알리미", layout="wide")
st.title("어르신과 보호자를 함께 지키는 폭염·한파 안전 알리미")

with st.sidebar:
    person = st.selectbox("어르신 선택", ["김○○ (82세, 혼자 거주)", "이○○ (74세)", "박○○ (70세)"])
    season = st.radio("계절", ["여름", "겨울"])
    faults = []
    if st.checkbox("기상청 API 장애 주입"): faults.append("weather")
    if st.checkbox("LLM 형식 오류 주입"): faults.append("llm")
    run = st.button("알림 확인하기", type="primary")

if run:
    with st.spinner("확인 중..."):
        try:
            res = requests.post(f"{API_URL}/alert",
                json={"person": person, "season": season, "fault": faults}, timeout=60).json()
        except Exception:
            st.error("서버에 연결할 수 없어요. 잠시 후 다시 시도해 주세요.")
            st.stop()

    if res.get("status") == "no_alert":
        st.success("오늘은 특별히 위험하지 않아요. 알림을 보내지 않습니다.")
    else:
        color = COLORS.get(res["risk_level"], "#555")
        left, right = st.columns(2)
        with left:
            st.markdown(f"""<div style="border:4px solid {color};border-radius:12px;padding:24px">
              <div style="color:{color};font-size:28px;font-weight:700">{res['risk_level']}</div>
              <div style="font-size:30px;line-height:1.5">{res['elder_message']}</div></div>""",
              unsafe_allow_html=True)
        with right:
            st.subheader("보호자 알림")
            st.write(res["guardian_message"])

    st.subheader("실행 과정")
    st.dataframe(res.get("logs", []))
```

```json
  "guardian_message": "...",
  "data_source": "cache",      // live / cache

  "logs": [{"step": "weather", "attempt": 1, "status": "retry", "error": "timeout"}]

```
오늘은 이 JSON을 코드에 고정값으로 넣고 화면부터 완성하세요. 내일 백엔드가 되면 `requests.post`로 바꾸기만 하면 됩니다.

## 5. 시연에서 꼭 보여줄 장면

1. **정상**: 체크박스 없이 실행 → 카드 2개 표시
2. **위험 없음**: 가을·취약도 하 인물 → "알림 보내지 않음" (Handoff Guard)
3. **API 장애**: 기상청 체크 → 로그에 재시도 → 캐시 사용, 카드는 정상 표시
4. **LLM 장애**: LLM 체크 → 템플릿 문구로 대체된 카드

3번에서 **"장애가 났는데도 어르신은 알림을 받았다"**가 한눈에 보이게 하는 게 핵심이에요. `data_source`가 cache면 카드 아래에 "14시 예보 기준" 같은 작은 안내를 붙이세요.
