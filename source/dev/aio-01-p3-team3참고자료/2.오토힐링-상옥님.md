AutoHealing 담당은 **"장애가 나도 서비스가 멈추지 않게 하고, 그걸 숫자로 증명하는 사람"**이에요. 이틀 범위에 맞춰 정리했습니다.

## 1. 해야 할 일 / 하지 말아야 할 일

| 해야 할 일 | 하지 말아야 할 일 |
|---|---|
| 재시도, 캐시 폴백, 템플릿 대체 구현 | 에이전트 호출 순서 결정 (오케스트레이터) |
| 장애 주입 기능 구현 | API 응답 파싱 (데이터·MCP) |

| 자동 복구율, 평균 복구시간 계산 | 로그에 API 키·지병 정보 남기기 |

## 2. 구현할 것

**① SQLite 테이블 2개**
```sql
CREATE TABLE cache (
  key TEXT PRIMARY KEY,      -- 예: weather_60_127
  value TEXT,                -- JSON
  saved_at TEXT
);
CREATE TABLE run_logs (
  task_id TEXT, step TEXT, attempt INT,
  status TEXT,               -- success / retry / fallback / fail
  error TEXT, recovery TEXT, elapsed_ms INT, created_at TEXT
);
```

**② 재시도 + 캐시 폴백 (날씨용)**
```python
def with_healing(cache_key, fetch, task_id, fault=None, retries=3):
    start = time.time()
    for attempt in range(1, retries + 1):
        try:
            if fault == "weather":
                raise TimeoutError("주입된 장애")
            result = fetch()
            save_cache(cache_key, result)
            log(task_id, "weather", attempt, "success", elapsed(start))
            return {"data": result, "source": "live"}
        except Exception as e:
            log(task_id, "weather", attempt, "retry", str(e))
            time.sleep(0.5 * attempt)

    cached = load_cache(cache_key)
    if cached:
        log(task_id, "weather", retries, "fallback", recovery="cache", elapsed_ms=elapsed(start))
        return {"data": cached, "source": "cache"}

    log(task_id, "weather", retries, "fail")
    raise RuntimeError("날씨 복구 실패")
```
데이터·MCP 담당이 만든 `fetch` 함수를 이 안에 넣어 감싸는 방식이라 서로 코드가 안 섞여요.

**③ LLM 형식 오류 복구**
- LLM 출력을 JSON으로 파싱하고 필수 키가 있는지 확인
- 실패하면 "JSON 형식으로만 답하라"는 지시를 덧붙여 1회 재요청
- 그래도 실패하면 고정 템플릿 문구 사용: "오늘 날씨가 위험해요. 가까운 쉼터에서 쉬세요."
- 장애 주입: `fault="llm"`이면 일부러 깨진 문자열을 반환

**④ 복구 지표 계산**
```sql
-- 자동 복구율: 장애가 있었던 task 중 최종 성공한 비율
-- 평균 복구시간: fallback 기록의 elapsed_ms 평균
SELECT AVG(elapsed_ms) FROM run_logs WHERE status = 'fallback';
```

## 3. 팀원과 맞출 것

| 누구와 | 무엇을 |
|---|---|
| 데이터·MCP | `fetch` 함수 이름과 반환 형식 |
| 오케스트레이터 | 반환값의 `source`(live/cache) 표시, 최종 실패 시 예외로 알릴지 |
| LLM 에이전트 | 필수 키 목록, 템플릿 문구 |
| 프런트 | 장애 주입 옵션 이름(`weather`, `llm`), 로그 표시 형식 |
